# Pandas Folder Overview

This folder contains exercises for working with tabular data using pandas. Pandas is a powerful Python library for data manipulation, analysis, and time-series processing.

## Why pandas matters

- Pandas provides convenient data structures like DataFrame and Series.
- It simplifies reading and writing data from CSV, Excel, and other formats.
- Pandas makes it easy to filter, aggregate, group, and reshape data.
- It is widely used in data science workflows alongside NumPy and visualization libraries.

## Learning Objectives

- Load tabular data into pandas DataFrames.
- Clean and transform columns and rows.
- Use indexing, filtering, and grouping operations.
- Compute summary statistics and create derived features.
- Work with real datasets such as ecommerce purchases and the iris dataset.
