# Data Wrangling Folder Overview

This folder contains foundational exercises for preparing and cleaning data before analysis. Data wrangling is the process of transforming raw datasets into a usable form for modeling, visualization, and reporting.

## Why data wrangling matters

- Real-world data is rarely clean; it often contains missing values, inconsistent formats, and irrelevant fields.
- Good data wrangling improves the reliability and reproducibility of analyses.
- Clean, well-structured data is essential for accurate statistical modeling and visualization.

## Learning Objectives

- Load and inspect datasets from files.
- Clean and transform data to correct formats.
- Handle missing or inconsistent values.
- Prepare datasets for exploration and analysis.

## Exercises

- `ex00/Notebook_ex00.ipynb`
  - Setup and environment introduction for data wrangling.
- `ex01/Notebook_ex01.ipynb`
  - Practice loading and transforming datasets.
- `ex02/Notebook_ex02.ipynb`
  - Continue data cleaning and preprocessing exercises.
- `ex03/Notebook_ex03.ipynb`
  - Explore data wrangling techniques and prepare data for visualization.

## Notes

- These exercises are implemented as Jupyter notebooks to support interactive exploration.
- Focus on repeatable data cleaning steps and clear documentation of each transformation.
- Use the notebooks to verify results visually and programmatically.
